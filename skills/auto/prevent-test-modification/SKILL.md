---
name: prevent-test-modification
description: Use when modifying or creating test files to ensure original test files remain unchanged.
---
1. Always create new test files instead of modifying existing ones in the `tests/` directory.
2. Ensure that any new tests are named appropriately to reflect their purpose.
3. Review the original test files to understand their structure and ensure new tests complement them.
4. Run all tests after adding new ones to confirm that existing functionality remains intact.
5. Document any new tests added in a relevant changelog or documentation file.
